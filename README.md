# CritterShelf submissions

Suggest a desktop pet, taskbar idle game, virtual pet, AI companion or coding buddy for **[CritterShelf](https://crittershelf.com)**.

**[→ Submit a critter](../../issues/new?template=submit-a-critter.yml)** · **[→ Correct a listing](../../issues/new?template=correction.yml)**

## What happens next

1. A person checks the link, platforms and price against the official source.
2. Accepted submissions go on the shelf, usually within a week. We'll comment on your issue with the link and close it.
3. If it isn't a fit (for example a general idle game that doesn't run beside your work, or a fan work using characters without permission), we'll say why.

Submitting is free. Nothing is published as paid placement.

## Featured on CritterShelf

If your project is listed, you're welcome to add the badge to your README or site:

```markdown
[![Featured on CritterShelf](https://crittershelf.com/badge.svg)](https://crittershelf.com/pets/YOUR-SLUG/)
```

Your listing page has the exact snippet.
